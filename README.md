# JUT ECE Virtual Lab

Advanced Electronics and Communication Engineering Virtual Laboratory with circuit simulations, logic gate builder, experiment manuals, quizzes, and Gemini AI assistant.

## Features
- **Offline-First Room Sync**: Built with robust offline capability using Supabase Realtime synchronization.
- **Interactive Simulators**: Logic Gate Builder, Breadboard, and Oscilloscope.
- **Gemini AI Tutor**: Integrated conversational AI assistant for physics and engineering concepts.
- **Neo-Brutalist Design**: Visually distinctive UI conforming to Material 3 but leveraging bold shapes and colors.
- **Tools**: Includes Resistor color code calculators, reactance, decibel, and dBm-Watts engineering tools.
